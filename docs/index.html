Try it yourself

Animate is a Claude Code plugin. It renders with Node 18+, Playwright's Chromium and ffmpeg (see the repo README), so it needs a real machine to run on. The full render pipeline has not been verified in ordinary Claude chat.

On a computer with Claude Code:

/plugin marketplace add cth9191/animate
/plugin install animate@animate

This repo ships a .claude-plugin/marketplace.json, so it registers as a marketplace directly. Then install the requirements: npm i -g playwright && npx playwright install chromium, and ffmpeg on your PATH.

From your phone: open the Code tab in the Claude app (iOS/Android, signed in with your claude.ai account). You can steer a session running on your computer (Remote Control), or start a cloud session on this repo (if your plan and organization allow cloud sessions; GitHub connected). Note: cloud sessions don't load installed plugins and have no plugin browser (docs), so there ask the session to use the skill folder directly (plugins/animate/skills/animate) and to install the requirements on its VM. The cloud-session setup below is documentation-based and has not been run-tested here.

Related motion skills and tools

A 20-item list of repos for motion, 3D, sound and video export, from a public post by @nanajiang8888 (Nov 22, 2026). Listed here as pointers only; this page has not tested them.

Motion skills

  • motion-design-skill: timing, easing, Disney's twelve principles
  • Motion: spring animation and transitions
  • Remotion Skills: official skills for making video
  • hairline: interactive line-art animation from an idea or an SVG
  • anatomy: 3D-style diagrams of machines and structures
  • anatomy-reveal: exploded product views and highlight videos

3D and effects

  • Blender: rigging and character animation
  • three.js: 3D scenes and camera moves
  • react-three-rapier: physics for 3D
  • react-postprocessing: glow, depth of field, film effects
  • three.quarks: particles and trails

Animation and video engines

  • Tweakpane: live parameter tweaking
  • GSAP: animation timelines, now free
  • Remotion: video with React
  • Manim: diagrams, formulas, explainer animation
  • Lottie: lightweight vector animation playback

Sound, captions and export

  • Openverse API: free sound effects, ambience and music, no key
  • librosa: beat detection to cut on the beat
  • WhisperX: automatic subtitle timing
  • FFmpeg: export and transcoding
