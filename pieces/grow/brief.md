# Grow - a tiny seed's story

An original demo piece made with the animate skill (cut-paper style) to show the pipeline on the fork's GitHub Pages.

- **Idea / device:** a seed becomes a sprout, then a tree, then a new seed. The spark (hero) tends it and gains a ray each era. The end is the start, changed: the last frame holds a new seed with a fresh leaf.
- **Format:** F2 morph chain, 16s, 9:16, 24fps, 120 BPM. Three morphs: sun -> rain cloud, cloud -> tree crown, fruit -> seed.
- **Arc:** build (seed) / journey (rain) / peak (tree) / silence 11.5-12.0 / gift (a new seed, stab + sub at 12.0, warm chord).
- **Sound:** composed score in code (no external track, no voice). Motif: a rising fifth when something is planted or sprouts.
- **Facts:** none on screen - a wordless little story, no claims to check.
